## 如何用一个整数表达多个标记？

每一位可以表示一个成员是否存在。按位或合并集合，按位与检查交集。Lane 采用位集合，但真实调度还要考虑挂起、过期和通道关联，不能仅看一个数字。

## 用一个例子建立直觉

```jsx
const A = 0b001;
const B = 0b010;
const selected = A | B; // 0b011
console.log((selected & A) !== 0); // true
console.log(selected & -selected); // 最低置位
```
