# React 基础教程 · 先会使用，再读源码

这一学习路线根据 [React 官方 Learn](https://react.dev/learn) 的 UI 描述、交互、状态管理和 Escape Hatches 组织，并补充路由、TypeScript、测试和工程实践。该教材是原创中文学习材料，示例以 React 19 为语义基线；固定源码阅读使用仓库内 React v19.3.0 缓存。

| 阶段 | 对应目录 | 内容 | 预期能力 |
| --- | --- | --- | --- |
| 第一阶段 | `01-start/`（01–08） | React、Vite、JS、组件、JSX、样式和纯渲染 | 能独立搭建并编写组件 |
| 第二阶段 | `02-ui/`（09–18） | Props、children、条件、列表、事件、State、表单和状态提升 | 能完成可交互的业务页面 |
| 第三阶段 | `03-hooks/`（19–26） | Effect、Ref、Memo、Reducer、Context、自定义 Hook 和规则 | 能正确组织副作用与复杂状态 |
| 第四阶段 | `04-engineering/`（27–34） | 路由、请求、TS、懒加载、测试、可访问性、性能与 Todo 实战 | 能完成可维护的完整练习 |

**如何在平台学习：** 左侧展开「React 基础」课程轨道，再选择 01–04 阶段；当前阶段会自动展开。在中间阅读中文教材、示例与练习，在右侧打开课程末尾链接的 React v19.3.0 源码或本项目源码。全局搜索、阅读进度与书签对基础教程同样生效。

**推荐衔接：** 基础阶段 → 既有「学习起点」 → React 运行时主线 → Hooks 与状态 → 调度与并发 → 浏览器与事件 → 服务端与架构 → 实验与验收。

注意：React 的基础教程和右侧 React v19.3.0 源码属于不同阅读层次；教学代码做了简化，不应当作 React 内部真实实现。
