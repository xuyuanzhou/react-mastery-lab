## 核心知识

React 可以使用 if 提前返回、条件运算符在两个节点中切换、&& 在条件成立时显示节点。选择哪种写法取决于分支复杂度，复杂的加载、错误和成功状态通常使用明确的 if 更易维护。注意数字 0 与 && 的组合可能意外渲染 0。

## 实例：把知识应用到组件

```jsx
function Result({ loading, error, items }) {
  if (loading) return <p>加载中…</p>;
  if (error) return <p role="alert">{error}</p>;
  if (items.length === 0) return <p>暂无数据</p>;
  return <p>找到 {items.length} 条记录</p>;
}
```

**阅读代码的顺序：** 先辨认组件的输入与当前状态，再找事件或外部变化的触发点，最后预测下一次渲染会产生什么界面。对于带请求、DOM 或定时器的示例，注意执行环境与清理边界。

## 常见错误与正确做法

写 {items.length && <List />}，在长度为 0 时渲染出 0；把多个复杂三元嵌套得难以阅读。
