## 核心知识

React 的事件处理函数作为 Props 传给 JSX 元素，常见命名为 onClick、onChange、onSubmit。传递函数本身，不要在渲染时执行。阻止默认行为使用 preventDefault，阻止事件冒泡使用 stopPropagation；不同浏览器事件有不同的传播和默认行为。

## 实例：把知识应用到组件

```jsx
function Toolbar() {
  function submit(event) {
    event.preventDefault();
    alert('已提交');
  }
  return (
    <form onSubmit={submit}>
      <input name="query" />
      <button type="submit">搜索</button>
    </form>
  );
}
```

**阅读代码的顺序：** 先辨认组件的输入与当前状态，再找事件或外部变化的触发点，最后预测下一次渲染会产生什么界面。对于带请求、DOM 或定时器的示例，注意执行环境与清理边界。

## 常见错误与正确做法

写 onClick={handleClick()} 导致渲染时直接调用；误把 stopPropagation 当成阻止表单提交。

## 自检问题

**React 中怎样正确传入带参数的事件回调？**

使用匿名函数包一层，例如 onClick={() => select(id)}。
