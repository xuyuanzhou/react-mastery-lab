## 核心知识

受控输入把 input 的 value 或 checkbox 的 checked 与 React State 关联，再通过 onChange 更新它。表单提交时可以阻止默认导航，执行验证和提交逻辑。若使用 value 却不提供可用的 onChange，输入可能变成只读；不要在同一输入生命周期中随意切换受控与非受控。

## 实例：把知识应用到组件

```jsx
import { useState } from 'react';
export default function Login() {
  const [email, setEmail] = useState('');
  const valid = email.includes('@');
  return <form onSubmit={e => { e.preventDefault(); alert(email); }}>
    <label>邮箱 <input type="email" value={email}
      onChange={e => setEmail(e.target.value)} /></label>
    {!valid && <p>请输入有效邮箱</p>}
    <button disabled={!valid}>提交</button>
  </form>;
}
```

**阅读代码的顺序：** 先辨认组件的输入与当前状态，再找事件或外部变化的触发点，最后预测下一次渲染会产生什么界面。对于带请求、DOM 或定时器的示例，注意执行环境与清理边界。

## 常见错误与正确做法

错误地给 input 同时设置 value 与 defaultValue；用 value={undefined} 后又切换成字符串产生受控性警告。

## 自检问题

**受控和非受控输入的核心区别是什么？**

受控输入由 React State 决定当前值；非受控输入的值主要由 DOM 自己保存。
