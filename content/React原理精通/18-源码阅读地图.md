# 推荐源码笔记模板

每个函数都用统一格式记录：

```md
## dispatchSetState

文件：
ReactFiberHooks.js

输入：
fiber, queue, action

输出/副作用：
创建 Update；
选择 lane；
入队；
触发 Root 调度。

改变的数据：
queue.pending
fiber/root lanes

下一跳：
scheduleUpdateOnFiber

它解决的问题：
把用户态 setState 转成 Reconciler 可调度更新。
```

坚持这种笔记格式，源码不会越看越散。
