# 46. 当前平台的源码点击学习指南

## 1. 从教材进入源码

打开 [React Mastery Lab](https://xuyuanzhou.github.io/react-mastery-lab/)，左侧按课程顺序选章。正文里的源码链接和首页调用链可以直接打开右侧源码工作台，并定位到 React v19.3.0 固定版本中的文件或函数。例如从 [renderWithHooks](source:packages/react-reconciler/src/ReactFiberHooks.js#renderWithHooks) 开始，先读中文说明，再读函数输入、状态字段、关键分支和下一步调用。

右侧支持函数索引、文件树、全文源码搜索、前进后退和 GitHub 固定 tag 链接。切换到「本项目源码」可以学习这个 React + TypeScript 工程本身。

桌面端把鼠标移到教材与源码之间的竖向分隔线，向左拖动即可扩大源码窗口；向右拖动可还给教材空间。聚焦分隔线后也能用左右方向键微调。窗口宽度会保存在本机浏览器中，刷新后仍保留。

## 2. 中文注释怎样使用

关键函数行旁的「译」表示有人工编写的中文讲解。点击标记或「中文注释」标签中的条目，可看到：

1. 这个函数在整条调用链中负责什么；
2. 阅读时值得观察的字段、分支或不变量；
3. 对应的教材章节。

工具栏的「关闭注释」或讲解卡右上角的 × 都可以隐藏讲解层；需要时点击「显示注释」重新打开。**注释是覆盖在查看器上的教学解释，不写入官方源码。** 因而右侧代码、行号与固定 tag 的 GitHub 文件仍可直接核对。未注释的函数也可以照常用函数索引和源码搜索查看。

## 3. 推荐的第一次追踪

```text
createRoot → updateContainer → scheduleUpdateOnFiber
→ ensureRootIsScheduled → beginWork → renderWithHooks
→ completeWork → commitRoot
```

每到一个函数，只回答五个问题：输入是什么、读写什么状态、为什么此时处理、下一步交给谁、哪些分支被本次实验跳过。不要把讲解卡当成源码逐行翻译；它只指出主线与边界。

随后做一次 `useState` 实验：点击 [dispatchSetState](source:packages/react-reconciler/src/ReactFiberHooks.js#dispatchSetState)，对照 [Lab 02](labs/02-UpdateQueue与baseQueue-rebase.md) 推导同一队列中不同 lane 的更新怎样重放。

## 4. 源码阅读与真实断点是两种活动

本平台展示固定 tag 的官方源码缓存，方便定位和阅读；它不等于正在浏览器中执行的 React 进程。要验证真实调用顺序，需要版本匹配的 React 开发构建、Source Map、可触发目标分支的最小 Demo 和 DevTools。请继续阅读 [源码调试环境](41-源码编译运行与调试环境.md) 与 [断点调试手册](debugging/断点调试手册.md)。

早期的独立源码学习器仍保留在 [`source-learning-app/`](source-learning-app/README.md) 作为历史资料；日常课程以当前 React Mastery Lab 平台为准。
