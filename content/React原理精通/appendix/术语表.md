# React Mastery 术语表

> **推荐使用新版完整词表：** [专业术语中英对照表](专业术语中英对照表.md)。该表统一采用 English → 中文，并用于各章术语映射。

- **Fiber**：React Reconciler 的工作/状态节点，承载树关系、props/state、lanes、flags 等。
- **Current Tree**：当前已经 Commit、代表用户可观察 UI 的 Fiber 树。
- **WorkInProgress (WIP)**：正在构建的候选 Fiber 树。
- **Alternate**：current 与 WIP 对应 Fiber 之间的双向关联。
- **Reconciliation**：根据新 UI 描述与 current Fiber 决定复用/创建/删除/移动的过程。
- **Render Phase**：构造候选 Fiber 树并计算副作用标记的阶段。
- **Commit Phase**：把完成的 Render 结果应用到 Host/Ref/Layout/Passive 等可观察系统。
- **Lane**：表示更新集合与调度语义的位集合模型，不等于线程优先级。
- **Update**：一次 state/root/class 等状态变化的内部记录。
- **UpdateQueue**：保存/组织 Update、支持跳过和重放的结构。
- **Hook**：FunctionComponent 在 Fiber 上按调用顺序连接的持久状态槽位。
- **Dispatcher**：决定当前 Hook API 使用 mount/update/rerender 等实现的内部接口。
- **Bailout**：确认当前 Fiber/子树在当前 lanes 下无需继续做特定工作。
- **Flag**：Render 阶段为 Commit 阶段记录的副作用/宿主操作标记。
- **Host**：React 所渲染到的环境，例如 DOM、Native、Canvas 自定义环境。
- **Host Config**：Renderer 向 Reconciler 提供的宿主操作接口集合。
- **Suspense**：对“当前结果暂不可用但可恢复”的协调机制。
- **Ping**：被等待资源 settle 后唤醒 Root/lanes 重新尝试的信号。
- **Hydration**：客户端 Fiber 与已有 server host nodes 匹配并接管的过程。
- **Fizz**：React 服务端 HTML streaming renderer 的内部体系称呼。
- **Flight**：React Server Components 的可流式数据协议体系称呼。
- **Tearing**：同一逻辑 UI 在一次用户可观察状态中读取到不一致的外部 store snapshot。
- **Rebase**：跳过不同优先级 Update 后，后续重新以正确基线重放更新以保持语义。
