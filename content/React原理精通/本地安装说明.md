# 本地安装说明

目标目录：

```text
/Users/xuyuanzhou/Desktop/个人/全栈面试/前端/React原理精通
```

## 方法一：双击安装脚本

1. 解压 `React原理精通.zip`。
2. 打开解压后的 `React原理精通` 文件夹。
3. 双击 `安装到指定目录.command`。
4. 脚本会创建目标目录并使用 `rsync` 同步全部 Markdown、实验、题库和答案。

如果 macOS 因安全设置阻止首次运行，可右键脚本选择“打开”，或在终端中执行：

```bash
chmod +x ./安装到指定目录.command
./安装到指定目录.command
```
