# React Mastery Lab：源码学习平台

这份原教材中的“源码点击学习器”已经整合进当前 `react-mastery-lab` Web 应用，不再需要单独启动旧静态工具。

在线学习时：

1. 左侧选择 Markdown 课程；
2. 正文里的 React 内部函数名可联动右侧 React v19.3.0 官方源码；
3. 右侧“相关课程”可以从源码反查教材；
4. “交互实验室”用于观察 Fiber、Hooks、UpdateQueue、Lane、Effect、Diff 与 Render/Commit 模型。

源码阅读器固定官方 `facebook/react` 的 `v19.3.0` tag，避免教材与 `main` 分支持续变化造成错位。
