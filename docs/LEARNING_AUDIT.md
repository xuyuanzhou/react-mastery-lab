# React Mastery Lab：课程与工程终审

> 复核日期：2026-10-06。这里记录课程能教什么、还不能保证什么，以及下一次扩写的优先级。它是审查记录，不是“学完即自动精通”的证明。

本审查以“能解释公共行为、沿固定版本源码追踪、实现关键机制、在应用中作出正确设计并用实验验证”为目标。读完页面本身不能保证精通；能力由可复现的实验、源码证据和独立实现来验收。React 内部实现固定参考 `v19.3.0`，公共 API 以 [React 官方参考](https://react.dev/reference/react)为准。

| 学习层 | 当前入口 | 验收方式 |
|---|---|---|
| 先修与用户模型 | `prerequisites/`、00P、00D、47 | 能画出状态所有权、Render 快照、事件与 Effect 的边界；不预设懂链表/DFS/位运算 |
| 更新主干 | 00B、00、01–10、37–38 | 从一次 `setState` 追到 Hook Queue、Lane、WIP、Commit 和屏幕像素；能说明可中断边界 |
| 核心 API 与宿主 | 11–13、16、24、26–35、48 | 用最小例子预测身份、Effect、Context、受控输入与可访问交互，并写行为测试 |
| 并发与服务端 | 14–15、20–21、31、36、39 | 区分 Suspense、Transition、SSR/Hydration、RSC、外部 Store 的问题与边界 |
| 架构与性能 | 17、19、22–25、34、40–45 | 对照源码解释 Reconciler/Renderer、Compiler 与性能权衡；用 Profiler/浏览器证据验证 |
| 动手验收 | `labs/`、`assessments/`、`mini-react/` | 先预测、运行、记录结果、解释偏差；复现失败后再对照官方源码 |

推荐顺序为“先修 → 用户模型与状态所有权 → Element/Fiber/Render/Commit → Hooks/Queue → Lane/并发 → 浏览器 → 服务端 → 架构 → Labs/Mini React/综合题”。课程树按这一因果顺序组织；12 周安排只是可选练习节奏，不是毕业时限。

### 仍需继续扩写的内容

34 篇基础课适合建立第一遍概念地图，但大多数章节仍是短篇导读：一个小例子、一组常见错误和少量自检，不能单靠它们证明读者已能独立设计复杂应用。后续应优先把 **State 快照与批处理、身份与 key、Effect 清理与竞态、受控输入、状态所有权、性能测量** 扩为“错误预测 → 可运行对照实验 → 逐步推导 → 源码定位 → 迁移练习”的完整课程。每次扩写要留下可复现输入、期望输出和答案证据，而不是只增加字数。

源码进阶有大量机制材料，但页面测试主要验证结构、链接和几个关键运行行为，不能保证每个解释都与固定版本完全一致。新增或修订涉及调度、Suspense、SSR/RSC、Compiler 的结论时，应在指定版本的源码和官方文档中逐条复核，并记录前提条件。教学 Mini React 可用于验证概念，不能把它的时序和能力当成官方实现。

工程代码可作为 React + TypeScript + Vite 静态内容平台的学习例子。若要拿它作为企业级业务应用起点，还需要根据实际场景补齐身份鉴权、服务端数据约定、错误监控、端到端测试、部署环境和安全策略；这些不属于当前静态教材站的已实现能力。

### 毕业验收建议

每个里程碑至少完成四件事：**预测**一个尚未运行的例子；**解释**结果依赖的公共规则；**定位**固定版本源码中的证据；**迁移**到一个改变前提的新例子并写测试。能够复述页面文字或点击“已读”只表示完成阅读，不表示通过验收。学习时间由达标情况决定，不设固定周数。

本轮补齐了两个容易缺失的能力：一是业务状态建模与自定义 Hook 的数据所有权（47），二是行为测试与可访问性验收（48）。Mini React 不再只有设计任务，还提供仓库内可运行源码、行为测试和右侧可点击的 `project:` 锚点。教材明确区分它与官方 React 的 Scheduler、DOM、Suspense 等实现。新增章节有草稿模板、结构校验、源码锚点与内链校验、人工审阅流程；手写和 AI 辅助走同一入口。

仍需保持诚实的边界：Mini React 是教学子集，不能替代官方运行时；服务器、Compiler 和复杂浏览器行为主要通过固定源码阅读与独立实验掌握。结构校验能证明链接和工程一致性，不能自动证明所有技术叙述准确。新章节应附原始证据、可运行实验、逐题答案，并由贡献者人工核对。[贡献说明](../CONTRIBUTING.md)规定了发布路径。
